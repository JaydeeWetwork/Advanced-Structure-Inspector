        Libraries & runtimes

        • three.js — 3D preview
        • stats.js — FPS panel
        • lil-gui — preview options UI
        • nbtify-readonly-typeless — NBT parse for structures
        • mcbe-leveldb-reader — extract structures from worlds
        • @zip.js/zip.js — zip / pack I/O
        • potpack — texture atlas packing
        • deepmerge — JSON resource merge
        • tga-js — TGA texture decode
        • strip-json-comments — JSONC parse
        • HoloPrint pack UI (separate page) may load @supabase/supabase-js
        • Loaded via esm.sh
