        Libraries & runtimes

        • three.js — 3D preview
        • nbtify-readonly-typeless — read .mcstructure NBT
        • nbtify — write .mcstructure NBT
        • @zip.js/zip.js — zip / .mcpack / .mcaddon ingest (on demand)
        • mcbe-leveldb-reader — .mcworld / .mctemplate import (on demand)
        • potpack — texture atlas packing
        • tga-js — TGA texture decode (on demand)
        • deepmerge — overlay resource-pack JSON merge (on demand)
        • CDN via esm.sh for the libraries above (except local JSONC comment stripping)
