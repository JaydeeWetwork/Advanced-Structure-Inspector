    Import structure files to build a browsable catalog. Parsing and world/pack extraction reuse HoloPrint core modules; this fork adds a catalog UI for local or static-web viewing.

    • Parse .mcstructure NBT (size, palette, origin, block counts)
    • Extract templates from worlds and HoloPrint packs
    • Optional 3D preview via existing pack/preview pipeline

    Persistence of structure binaries (IndexedDB / OPFS) is planned next — this scaffold keeps files in session memory and stores a metadata index in localStorage.
